# agrosilo-poo-java
Sistema em Java (CLI) para gestão de estoque e valoração financeira de grãos (soja) em cooperativas agrícolas, desenvolvido com arquitetura MVC, padrões de projeto (DAO, Strategy, Factory, Decorator), dupla persistência (Memória/MariaDB), cache de cotações e suporte multilíngue (PT, EN, ES)
